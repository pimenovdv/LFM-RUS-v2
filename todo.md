# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-69)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM, включая базовый сэмплинг, динамические расписания, Classifier-Free Guidance, Watermarking, Classifier-Guided Sampling, Continuous Batching и Dynamic Batching, Beam Search, Speculative Decoding, LoRA, оптимизацию памяти, RLAIF, Mixture of Experts (MoE) и Retrieval-Augmented Generation (RAG). Внедрена поддержка непрерывного времени (Continuous Time Diffusion) для дискретных токенов для более гибкого сэмплинга (ODE/SDE).

## [ ] Шаг 70: Внедрение Consistency Models (Дистилляция консистентности) для MDLM
**Цель:** Реализовать поддержку дистилляции консистентности (Consistency Distillation) для маскированной диффузии. Это позволит модели генерировать текст за 1-2 шага расшумления, достигая качества, сопоставимого с сотнями шагов диффузии, за счет обучения функции, напрямую отображающей зашумленные состояния в исходные токены.
