# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-55)
**Сжатое описание:**
Реализована базовая интеграция MDLM с обширным набором методов сэмплинга и параметров генерации:
- Поддержка CFG, Guidance Rescale, Activation Steering, Negative Prompting, Watermarking (SynthID, KGW).
- Динамические расписания для множества параметров (temperature, cfg, штрафы, top_k/p/a и т.д.).
- Алгоритмы сэмплинга, принудительное декодирование, стратегии ремаскинга (вкл. entropy), и gumbel noise.

## [x] Шаг 56: Реализация Classifier-Guided Sampling
**Цель:** Внедрена возможность использовать внешний классификатор для навигации процесса генерации (добавление градиентов классификатора к логитам во время демаскирования). Реализовано с поддержкой различных динамических расписаний (linear, cosine, exponential, cyclic).

## [ ] Шаг 57: Интеграция Beam Search для MDLM
**Цель:** Разработать и внедрить алгоритм Beam Search, адаптированный под процесс итеративного демаскирования диффузионных языковых моделей для улучшения качества генерации.
