# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-62)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM, включая базовый сэмплинг, динамические расписания, Classifier-Free Guidance, Watermarking, Classifier-Guided Sampling, Continuous Batching, алгоритмы Beam Search и Speculative Decoding. Проведена оптимизация памяти (FlashAttention) и добавлена поддержка RLAIF (Constitutional AI).


## [ ] Шаг 63: Поддержка Dynamic Batching
**Цель:** Реализовать поддержку динамического батчинга (Dynamic Batching) для объединения запросов разной длины в один батч во время инференса, что улучшит пропускную способность.
