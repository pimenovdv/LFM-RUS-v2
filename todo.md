# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-57)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM с обширным набором методов сэмплинга и параметров генерации. Основные реализованные фичи:
- Базовый сэмплинг, динамические расписания (temperature, CFG, штрафы), принудительное декодирование и Gumbel noise.
- Classifier-Free Guidance (CFG), Guidance Rescale, Activation Steering, Negative Prompting, Watermarking (SynthID, KGW).
- Интеграция Classifier-Guided Sampling с поддержкой динамических расписаний.
- Адаптация алгоритма Beam Search для процесса итеративного демаскирования (MDLM).

## [x] Шаг 58: Поддержка непрерывного батчинга (Continuous Batching) для MDLM
**Цель:** Реализовать поддержку непрерывного (in-flight) батчинга при инференсе MDLM для максимальной утилизации GPU в высоконагруженных сценариях, что позволит эффективно обрабатывать запросы разной длины и с разным количеством шагов диффузии параллельно.

## [ ] Шаг 59: Оптимизация KV-Cache и маскирования (FlashAttention для MDLM)
**Цель:** Внедрить оптимизации работы с памятью и вычислениями внимания через интеграцию специализированных ядер (например, FlashAttention) с учетом специфики двунаправленного внимания и итеративного маскирования в MDLM.

## [ ] Шаг 60: Интеграция RLAIF для LFM
**Цель:** Внедрить поддержку алгоритма RLAIF (Constitutional AI), используя локальную модель для генерации кандидатов и внешнего LLM-судью для их оценки в соответствии с конституциональными правилами, повышая тем самым уровень выравнивания LFM моделей.

## [ ] Шаг 61: Динамическое расписание маскирования на основе энтропии
**Цель:** Реализовать новый тип schedule для демаскирования, который будет динамически адаптировать количество токенов для демаскирования на каждом шаге на основе средней энтропии распределения предсказаний модели, позволяя быстрее проходить участки с высокой уверенностью.
