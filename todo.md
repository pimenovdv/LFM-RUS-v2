# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-66)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM, включая базовый сэмплинг, динамические расписания, Classifier-Free Guidance, Watermarking, Classifier-Guided Sampling, Continuous Batching и Dynamic Batching, алгоритмы Beam Search и Speculative Decoding, а также добавлена поддержка Low-Rank Adaptation (LoRA). Проведена оптимизация памяти (FlashAttention) и добавлена поддержка RLAIF (Constitutional AI). Интеграция KV-кэша исключена по архитектурным причинам. Добавлена архитектура DiffusionControlNetModel для жесткого/мягкого кондиционирования на внешних структурах.

## [ ] Шаг 67: Внедрение Mixture of Experts (MoE) в архитектуру диффузионных моделей
**Цель:** Добавить возможность использования архитектуры Mixture of Experts (MoE) для увеличения параметров диффузионной модели без существенного увеличения вычислительной сложности на инференсе и обучении, включая роутинг экспертов и распределение нагрузки.

## [ ] Шаг 68: Добавление поддержки интеграции с внешними поисковыми движками (RAG для Диффузии)
**Цель:** Разработать механизм Retrieval-Augmented Generation (RAG) специально адаптированный для маскированной диффузии, позволяющий модели на ранних шагах расшумления делать запросы к векторной БД для уточнения фактологии и контекста.
