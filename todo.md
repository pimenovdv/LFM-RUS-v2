# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-61)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM с обширным набором методов сэмплинга и параметров генерации. Основные реализованные фичи:
- Базовый сэмплинг, динамические расписания (temperature, CFG, штрафы), принудительное декодирование и Gumbel noise.
- Classifier-Free Guidance (CFG), Guidance Rescale, Activation Steering, Negative Prompting, Watermarking (SynthID, KGW).
- Интеграция Classifier-Guided Sampling с поддержкой динамических расписаний.
- Адаптация алгоритма Beam Search для процесса итеративного демаскирования (MDLM).
- Поддержка непрерывного батчинга (Continuous Batching) для эффективного инференса.
- Оптимизация памяти через интеграцию FlashAttention для двунаправленного внимания.
- Интеграция RLAIF (Constitutional AI) для выравнивания моделей.
- Динамическое расписание маскирования на основе энтропии для более быстрого и уверенного демаскирования участков генерации.

## [ ] Шаг 62: Интеграция Speculative Decoding для MDLM
**Цель:** Реализовать поддержку алгоритма Speculative Decoding, позволяя использовать малую модель (draft) для предварительной генерации токенов, с последующей верификацией целевой (target) моделью, что должно кратно ускорить инференс дискретной диффузии.
