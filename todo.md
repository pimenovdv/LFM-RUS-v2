# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-63)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM, включая базовый сэмплинг, динамические расписания, Classifier-Free Guidance, Watermarking, Classifier-Guided Sampling, Continuous Batching и Dynamic Batching, алгоритмы Beam Search и Speculative Decoding. Проведена оптимизация памяти (FlashAttention) и добавлена поддержка RLAIF (Constitutional AI).

## [ ] Шаг 64: Интеграция KV-кэша для MDLM
**Цель:** Добавить поддержку передачи и использования KV-кэша во время итеративного анмаскинга для ускорения генерации длинных последовательностей, избегая пересчета уже известных токенов префикса.
