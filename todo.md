# План внедрения обучения Diffusion Language Models (MDLM) в пайплайн LFM-RUS-v2

Этот документ содержит пошаговый план разработки для интеграции маскированной дискретной диффузии в существующий пайплайн обучения.

## [x] Завершенные этапы (Шаги 1-64)
**Сжатое описание:**
Реализована полнофункциональная интеграция MDLM, включая базовый сэмплинг, динамические расписания, Classifier-Free Guidance, Watermarking, Classifier-Guided Sampling, Continuous Batching и Dynamic Batching, алгоритмы Beam Search и Speculative Decoding. Проведена оптимизация памяти (FlashAttention) и добавлена поддержка RLAIF (Constitutional AI). Исследована возможность интеграции KV-кэша, которая признана архитектурно несовместимой с двунаправленной диффузией; добавлена явная ошибка (`NotImplementedError`) для стабильности.

## [ ] Шаг 65: Реализация поддержки LoRA для диффузионных моделей
**Цель:** Добавить возможность адаптации и дообучения диффузионных моделей на специфичных задачах с использованием Low-Rank Adaptation (LoRA), обеспечивая гибкую настройку конкретных слоев архитектуры.

## [ ] Шаг 66: Добавление поддержки ControlNet-подобного кондиционирования
**Цель:** Расширить пайплайн генерации текста возможностью жесткого или мягкого кондиционирования на внешних структурах (например, семантические графы или POS-теги) по аналогии с архитектурой ControlNet для диффузии.
